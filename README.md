# munaza-ashraf.github.io

Personal portfolio site for Munaza Ashraf — a single static `index.html` (inline CSS, no build step).

- **Preview locally:** `python3 -m http.server 8000` then open http://localhost:8000
- **Deploy:** push to `main`; GitHub Pages serves the repo root.
- **Assets:** `assets/cv.pdf` (CV), `assets/img/munazaashraf.jpg` (profile photo).
